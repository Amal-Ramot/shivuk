# סורק מחירים 🛒

אתר שמתחבר לקבצי **שקיפות המחירים** שרשתות השיווק מחויבות לפרסם, ומאפשר:

1. לבחור רשת וסניף.
2. לסרוק ברקוד של מוצר במצלמה (או להקליד ברקוד / לחפש לפי שם).
3. לראות את שם המוצר, המחיר שלו בסניף והמחיר ל-100 גרם / 100 מ״ל / יחידה.
4. ללחוץ על **"מצא תחליף זול"** ולקבל רשימת מוצרים מאותה קטגוריה באותו סניף שזולים או משתלמים יותר (לפי מחיר ליחידת מידה), כולל אחוז החיסכון.

כתובת האתר: **https://amal-ramot.github.io/shivuk/**

## איך זה עובד

```
GitHub Actions (כל יום + בכל דחיפה)
  └─ scripts/fetch_prices.py
       ├─ מוריד רשימת סניפים + מחירון מלא (PriceFull) לכל סניף מכל רשת
       ├─ מסווג מוצרים לקטגוריות (scripts/categories.py)
       └─ כותב קבצי JSON ל-site/data/
  └─ מפרסם את התיקייה site/ ל-GitHub Pages
```

קבצי הרשתות לא נגישים ישירות מהדפדפן (CORS, קבצים דחוסים בגודל של מגה-בייטים לכל סניף), לכן
ההורדה והעיבוד נעשים מראש ב-GitHub Actions, והאתר עצמו סטטי ומהיר: הוא טוען רק את מחירון
הסניף שנבחר ואת חלק הקטלוג של הקטגוריה הרלוונטית.

### רשתות

| רשת | מקור |
| --- | --- |
| שופרסל | prices.shufersal.co.il |
| רמי לוי, אושר עד, יוחננוף, טיב טעם, דור אלון, קשת טעמים, פרשמרקט, סטופ מרקט, פוליצר | url.publishedprices.co.il |

רשת שלא מצליחים להוריד ממנה בהרצה מסוימת פשוט מדולגת, והסטטוס נרשם ב-`data/meta.json`.
להוספת רשת שמפרסמת בפורטל publishedprices — מוסיפים שורה ל-`CERBERUS_CHAINS` ב-`scripts/fetch_prices.py`
עם שם המשתמש הציבורי שהרשת מפרסמת באתר שלה.

### "תחליף זול" — מה נחשב תחליף?

* תחליף = כל מוצר בסניף מאותו **סוג מוצר**, בלי קשר למותג, לאריזה או לגודל.
  למשל מרכך כביסה של "סוד" ↔ כל מרכך כביסה אחר; צ'יפס קפוא של זוגלובק ↔ כל צ'יפס קפוא.
* סוג המוצר נקבע לפי מילות מפתח בשם (`scripts/categories.py`): כ-70 קטגוריות ובתוכן כ-250 סוגים
  (רטבים → קטשופ / מיונז / חרדל…, ירקות → עגבניות / מלפפונים…). הטעם ("בטעם…") לא משפיע על הסוג.
  מוצר שלא זוהה לו סוג מקובץ לפי המילה הראשונה בשמו (למשל "במבה").
* ממוינים לפי מחיר ל-100 גרם / 100 מ״ל / יחידה (**הכי משתלם**) או לפי המחיר בקופה (**הכי זול**), כולל מבצעים.
* "רק בגודל דומה" — מסנן לאריזות בגודל 60%–170% מהמוצר שנסרק.

## הפעלה ראשונה של GitHub Pages

ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
אחר כך: **Actions → "עדכון מחירים ופרסום ל-GitHub Pages" → Run workflow** (או לחכות להרצה היומית).

## הרצה מקומית

```bash
MAX_STORES=3 python3 scripts/fetch_prices.py --out site/data --chains shufersal,ramilevy
cd site && python3 -m http.server 8000
```

ואז לפתוח http://localhost:8000. (הסריקה במצלמה דורשת HTTPS או localhost.)

## הערות

* מבצעים: נלקחים מקובץ המבצעים המלא (PromoFull) של כל סניף. ההשוואה משתמשת במחיר המבצע הזול ביותר, כולל מבצעי מועדון/אשראי ומבצעים מותנים בסכום קנייה — שמוצגים עם הסבר על התנאי. קופונים ומתנות לא נכללים.
* **העדכון האוטומטי מושבת כרגע** — האתר מתעדכן רק בהרצה ידנית (Actions → Run workflow). כשהוא פעיל: המחירים מתעדכנים פעם ביום (06:17 שעון ישראל). שינוי בקבצי האתר (`site/`) מתפרסם תוך כדקה ומשתמש בנתוני המחירים השמורים מאותו יום; הורדה מלאה מחדש קורית רק בעדכון היומי, בהרצה ידנית או כשמשתנה קוד עיבוד הנתונים (`scripts/`).
